# 衣装索引 · 中文离线服装图库

与姿态索引一致的浏览界面：完整看图、中文搜索、分类与颜色筛选、收藏、集合、备注、最近浏览和四图参考台。

**[打开在线演示](https://1581610.github.io/ai-costume-gallery-offline-zh/)** · [素材原站](https://ai-costume-gallery.pages.dev/)

原素材作者：ギア（https://x.com/giaaibusi）。中文整理与浏览工具维护：1581610。

## 在线演示

在线页面通过原站地址加载图片，不在本仓库或 GitHub Pages 重新分发图片。需要联网；原站不可用或限制访问时图片可能无法显示。
收藏、集合和备注保存在浏览器。在线、本地服务及直接打开文件是不同入口，记录不会自动同步，可在帮助中导出／导入迁移。

## 获取离线素材

仓库只提供代码、原始元数据及中文整理，**不包含图片文件**。克隆或下载本仓库后，先从原站获取图片；下载完成后才能完整离线浏览。
需要 Python 和 Pillow；下面在项目内创建独立环境，不修改系统 Python：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install Pillow
.\.venv\Scripts\python scripts\download.py
```

下载约 1.42 GiB，支持断点续传。素材文件仅供遵守原作者规则的个人参考，使用范围以原站说明为准。

## 使用

双击 `打开图库.cmd`。已有 Python 时会启动仅监听 `127.0.0.1:8919` 的本地服务并打开浏览器，支持直接下载 PNG 原图。
关闭服务窗口即可停止。程序不会修改 PATH、系统网络配置或其他软件。

也可直接双击 `index.html` 离线浏览，无需安装依赖。直接打开 HTML 时，“打开原图”会在新标签页显示原图，可右键另存。
原图拖放由浏览器和接收软件决定；如接收区只得到地址，请用启动器打开，或先保存图片再导入。

## 素材与功能

- 共 1407 套：春季 215、夏季 254、秋季 244、冬季 253、内衣 199、派对 48、泳装 54、性感穿搭 140。
- 每套包含原始 PNG、预览 WebP 和缩略图，共 4221 个图片文件，约 1.42 GiB，保持原文件字节。
- 88 个英文检索词逐项汉化，支持中文、英文、编号及空格分隔的组合检索。
- 标题根据原始关键词整理；关键词可能与画面细节存在偏差。颜色和类型筛选匹配整套服装的检索词，不代表所有单件都具有该属性。
- 默认完整显示原图；滚轮／双指缩放，放大后拖动平移，镜像仅改变显示。
- 未放大时直接拖出原图；放大后 Alt＋拖动导出。左右键切换、F 收藏、空格切换适应／原尺寸、Esc 关闭。
- 每套附一条按画面反推的英文生图提示词：只写单品、版型、细节和颜色，不写评价；图片详情可复制单条，筛选结果可整批复制。提示词只描述服装本身，不含场地、背景、透明模特这类画面环境词，也不写「可见／穿着」这类描述照片的字眼，更不含模型、采样步数、画幅等生成参数，可直接粘贴后自行补充参数。
- 收藏、集合、备注与参考台保存于浏览器，可导出和合并导入个人资料。不同入口的记录独立，换入口前先备份。
- 本项目的个人备份与姿态索引、人像图库分别管理，不混用。
- 浏览本机图库不需要联网，也没有字体 CDN、统计脚本或远程 API 请求；在线版的图片与保存请求由原站提供。原作者网站和使用说明外链需要联网。

## 项目结构

```text
assets/images/       PNG 原图
assets/previews/     WebP 预览
assets/thumbnails/   WebP 缩略图
data/                原始元数据、翻译对照、中文索引与图片校验摘要
src/                 页面 HTML、CSS、JavaScript
scripts/             构建、下载和本地服务
tests/               浏览器交互与原图拖放验证
docs/                检查记录
index.html           可直接打开的离线页面
打开图库.cmd         推荐启动入口
```

重新构建离线入口：`python scripts/build.py`。在线入口：`python scripts/build.py --hosted`，输出在 `dist/index.html`，仅引用原站图片。构建只用标准库。
补齐图片：使用上面的独立环境运行 `.\.venv\Scripts\python scripts\download.py`，可恢复下载并验证图片格式和完整性，不覆盖已验证的正确文件。
开发检查：`node --check src/app.js`、`python tests/test_gallery.py`。浏览器检查使用隔离 Edge，不读取个人浏览器资料。
